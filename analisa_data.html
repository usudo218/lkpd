Materi Pelajaran Lengkap

1. Fondasi Pengolahan Data Statistik & Visualisasi Grafik

Pelajari rumus-rumus esensial dalam statistik deskriptif dan metodologi penyusunan diagram batang sebelum menjawab asesmen.

1. Rata-Rata (Mean - x̄)

Nilai representatif pusat data yang diperoleh dari jumlah seluruh nilai data dibagi banyaknya data ($n$).

x̄ = (∑ xᵢ) / n

Contoh data: 70, 80, 90. Rata-rata = (70 + 80 + 90) / 3 = 80.

2. Nilai Maksimum & Minimum

Batas ekstremum dataset untuk mengidentifikasi puncak tertinggi dan titik terendah data observasi.

X_maks = Max(x₁, x₂, ..., xₙ)
X_min = Min(x₁, x₂, ..., xₙ)

Menjadi acuan utama dalam menentukan dispersi persebaran data.

3. Jangkauan Data (Range - R)

Selisih mutlak antara nilai observasi tertinggi dengan nilai observasi terendah.

R = X_maks - X_min

Jika nilai tertinggi = 98 dan terendah = 42, maka R = 98 - 42 = 56.

4. Banyak Kelas (Aturan Sturgess)

Metode empiris standar untuk menentukan jumlah kelompok kelas interval ($k$) dari $n$ data.

k = 1 + 3.322 · log₁₀(n)

Nilai $k$ selalu dibulatkan ke bilangan bulat terdekat (umumnya pembulatan ke atas).

5. Panjang Interval Kelas (i)

Lebar cakupan nilai dalam setiap kelompok interval kelas.

i = R / k = (X_maks - X_min) / k

Jika R = 56 dan k = 6, maka i = 56 / 6 = 9.33 ≈ 10.

6. Kaidah Grafik Batang Profesional

Grafik batang menyajikan frekuensi atau agregasi nilai pada kategori tertentu secara terpisah.

• Sumbu X (Horizontal): Kategori / Label Interval.

• Sumbu Y (Vertikal): Frekuensi / Nilai (Mulai dari 0).

• Lebar Batang: Konsisten dengan celah antar batang seragam.

Studi Kasus: Pemetaan Hasil Asesmen Analisis Data Siswa (N = 30)

Penerapan perhitungan statistik deskriptif dan transformasi tabel ke visualisasi grafik batang.

Latihan Terpandu
Dataset Mentah Nilai Asesmen (30 Siswa):
[ 55, 60, 62, 65, 65, 68, 70, 72, 72, 74, 75, 75, 76, 78, 80, 80, 82, 84, 85, 85, 86, 88, 90, 90, 92, 94, 95, 96, 98, 100 ]

Perhitungan Parameter Statistik Dasar

  • • Banyak Data (n): 30 siswa
  • • Nilai Minimum (X_min): 55
  • • Nilai Maksimum (X_maks): 100
  • • Rata-Rata (Mean): ∑X / n = 2397 / 30 = 79.9
  • • Jangkauan (Range R): 100 - 55 = 45

Perhitungan Interval & Frekuensi

  • • Banyak Kelas (k): 1 + 3.322 · log₁₀(30) = 1 + 3.322(1.477) = 1 + 4.907 = 5.907 ≈ 6 Kelas
  • • Panjang Interval (i): R / k = 45 / 6 = 7.5 ≈ 8 Nilai
  • • Kelas Interval: 55–62, 63–70, 71–78, 79–86, 87–94, 95–102

Sumbu Y: Frekuensi (Siswa) | Sumbu X: Rentang Nilai

Interpretasi: Modus data berada pada rentang 71–86 (14 siswa berkumpul di kelompok ini), membentuk pola distribusi simetris unimodal mendekati kurva normal.
