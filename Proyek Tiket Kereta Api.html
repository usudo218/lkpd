01 DESKRIPSI SPESIFIKASI SISTEM TIKET KERETA

Spesifikasi Kasus

Anda diminta membuat program kasir penjualan tiket kereta api "Express Nusantara" dengan ketentuan tarif dasar per penumpang sebagai berikut:[cite: 2]

1. Kelas Ekonomi Rp80.000 / tiket[cite: 2]
2. Kelas Bisnis Rp150.000 / tiket[cite: 2]
3. Kelas Eksekutif Rp250.000 / tiket[cite: 2]

Ketentuan Tambahan & Diskon Bertingkat:[cite: 2]

  • Jika pembeli memesan ≥ 4 tiket, maka mendapatkan diskon rombongan sebesar 10% dari total harga dasar.[cite: 2]
  • Jika pembeli memilih kelas yang tidak tersedia (selain 1, 2, atau 3), program harus menampilkan pesan: "Kode kelas tidak valid!" dan tidak melanjutkan perhitungan.[cite: 2]
