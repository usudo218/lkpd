Bridge to Programming

Bagaimana Kode Python Menjalankannya? 🐍

Bahasa Pemrograman: Python 3
prediksi_nilai.py 
import numpy as np
from sklearn.linear_model import LinearRegression

# 1. Data Historis (X = Jam Belajar, Y = Nilai Ujian)
X = np.array([[1], [2], [3], [4]])
Y = np.array([50, 60, 70, 80])

# 2. Inisialisasi dan Latih Model Machine Learning
model = LinearRegression()
model.fit(X, Y)  # Komputer otomatis mencari pola rumus matematika!

# 3. Prediksi untuk Jam Belajar Baru (misal: 6 Jam)
jam_baru = np.array([[6]])
prediksi_nilai = model.predict(jam_baru)

print(f"Hasil Prediksi Nilai untuk 6 Jam Belajar: {prediksi_nilai[0]:.0f}")
# Output: Hasil Prediksi Nilai untuk 6 Jam Belajar: 100

Gold Rules Data Analyst Muda 🌟

1. Garbage In, Garbage Out 🗑️

Jika data masa lalu yang dimasukkan salah/rusak, hasil prediksimu pasti akan ikut salah!

2. Prediksi ≠ Kepastian 100% 📐

Prediksi memberikan **probabilitas kemungkinan tertinggi**, bukan takdir pasti tanpa celah.

3. Selalu Lakukan Validasi 🔍

Bandingkan terus hasil prediksi modelmu dengan data aktual untuk memperbaiki akurasi rumus.
