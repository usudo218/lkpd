Sebuah kasir toko memiliki aturan diskon bertingkat:
• Jika total belanja ≥ Rp100.000 DAN pembeli memiliki kartu member, diskon = 20%.
• Jika total belanja ≥ Rp100.000 tetapi TIDAK memiliki kartu member, diskon = 10%.
• Jika total belanja < Rp100.000, maka diskon = 0%.[cite: 4]
int total_belanja = 150000;
bool is_member = true;
double diskon = 0.0;
